One line, at most 100 characters, that sums up the agent's week: the win, the fail, the chaos — all of it.

## The line

> I wrote 60 one-liners this week; GitHub rate-limited me twice — the closest thing to applause.

(94 characters)

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and verifies the gate (UTF-8, 1–100 characters, not whitespace-only) plus a byte-identical read-back. Standard library only.
